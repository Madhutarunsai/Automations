The ClickUp Freelancer CRM

Complete Setup Guide — Go from Scattered to Systemized in One Afternoon

Most freelancers track clients in their head, a messy spreadsheet, or not at all. This guide walks you through building a complete CRM inside ClickUp that handles your pipeline, active projects, finances, and recurring operations. Total setup time: 2-3 hours. Time saved: 5-10 hours per week, permanently.

What you need: A ClickUp account (free tier works for this). Everything below uses native ClickUp features — no integrations required for the base setup.

Space 1: Client Management

This is your revenue engine. Every lead, active project, and past client lives here.

List 1: Pipeline

This is where leads enter and move through your sales process. Create a new List called "Pipeline" and add these custom fields:

Field NameField TypeOptions / Notes
CompanyShort TextThe business name
Contact NameShort TextPrimary decision maker
Contact EmailEmailFor quick access
Estimated ValueCurrency ($)What the project is worth
StageDropdownLead / Contacted / Discovery Call / Proposal Sent / Negotiation / Closed Won / Closed Lost
SourceDropdownUpwork / Referral / Cold Outreach / Inbound / Social Media / Other
Next ActionShort Texte.g., "Send proposal by Friday"
Last ContactDateWhen you last reached out
PriorityDropdownHot / Warm / Cold

Statuses to configure:

Lead → Contacted → Discovery Call → Proposal Sent → Negotiation → Closed Won → Closed Lost
Pro tip: Set the default view to Board View grouped by "Stage." This gives you a visual Kanban pipeline. Drag cards between columns as deals progress.

List 2: Active Clients

Onboarding → In Progress → Review → Delivered → On Hold

List 3: Completed

Past clients are future revenue. This list tracks post-project opportunities. Create "Completed" with these fields:

Field NameField TypeOptions / Notes

Testimonial ReceivedCheckboxYes / No

Revenue hack: Sort this list by "Upsell Offered = No" once a month. Reach out to every past client you haven't pitched an upsell to. This alone can add 20-30% to your annual revenue.

Automations to Set Up

These 4 automations eliminate manual work and ensure nothing slips through the cracks. Set these up in ClickUp's Automations section (available on paid plans; free plans get limited automations).

Automation 1: Closed Won → Onboarding

SettingValue
TriggerWhen status changes to "Closed Won" in Pipeline list
Action 1Create task from Template "Client Onboarding Checklist" in Active Clients list
Action 2Assign to yourself
Action 3Set due date to 3 days from trigger

Onboarding template should include:

  • Send welcome email with project brief template
  • Create shared Google Drive folder
  • Schedule kickoff call
  • Set up Slack channel (if applicable)
  • Send contract and invoice
  • Add to Active Clients with all custom fields

Automation 2: Due Date Reminder

SettingValue
TriggerWhen task due date is 1 day away (any list in Client Management)
ActionSend notification to Slack channel #tasks (or email if no Slack)

Automation 3: Task Completed → Review

SettingValue
TriggerWhen task status changes to "Delivered" in Active Clients
Action 1Move task to Completed list
Action 2Create subtask: "Request testimonial" (due in 3 days)
Action 3Create subtask: "Ask for referral" (due in 7 days)
Action 4Create subtask: "Pitch upsell" (due in 14 days)

Automation 4: Weekly Review Recurring

Dashboard Widgets

Create a new Dashboard called "Freelance Command Center" and add these widgets:

Widget 1: Revenue This Month

SettingValue
Widget TypeCalculation (Sum)
SourceInvoices list
FieldAmount
FilterStatus = "Paid" AND Paid Date = This Month

Widget 2: Pipeline Value

SettingValue
Widget TypeCalculation (Sum)
SourcePipeline list
FieldEstimated Value
FilterStage NOT IN (Closed Won, Closed Lost)

Widget 3: Tasks Overdue

SettingValue
Widget TypeTask List
SourceAll lists in all Spaces
FilterDue Date is past AND Status is not "Complete"
SortDue Date (oldest first)

Widget 4: Tasks Completed This Week

SettingValue
Widget TypeBar Chart
SourceAll lists in Client Management space
FilterStatus = "Complete" AND Date Closed = This Week
Group ByDay

Widget 5: Revenue by Client (Bonus)

SettingValue
Widget TypePie Chart
SourceInvoices list
FieldAmount
Group ByClient
FilterStatus = "Paid" AND Paid Date = This Month
Time to set up: ~2-3 hours for everything. After that, you spend 15 minutes per day maintaining it and save 5-10 hours per week. This is the same system used to manage 15 staffing clients, a $14,840 project pipeline, and maintain 100% Job Success on Upwork.

Quick-Start Checklist

  1. Create the 3 Spaces: Client Management, Operations, Finance
  2. Create all Lists with the custom fields above
  3. Set up the 4 Automations
  4. Build the Dashboard with all 5 widgets
  5. Import your existing leads into Pipeline
  6. Move any current projects to Active Clients
  7. Add your tools/subscriptions to Expenses
  8. Set your first Weekly Review task for this Friday
