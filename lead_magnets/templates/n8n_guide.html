5 n8n Automation Templates — Step-by-Step Setup Guides

These are the 5 automations I build most often for clients. Together they've powered projects up to $14,840 and helped 15 staffing firms streamline their operations. Each guide below walks you through every node, every connection, and every configuration — no guessing required.

1. Lead Follow-Up Sequence

What it does: When a new lead comes in via webhook (form, landing page, Calendly), it sends an immediate welcome email, waits 3 days, sends a follow-up with value, waits 4 more days, sends a closing email, and logs the entire sequence in a Google Sheet.

Setup time: 20-25 minutes

Node List (7 nodes)

#Node TypeNamePurpose
1WebhookNew Lead TriggerReceives incoming lead data (name, email, company)
2GmailWelcome EmailSends immediate acknowledgment email
3WaitWait 3 DaysPauses the workflow for 3 days
4GmailValue Follow-UpSends follow-up with a useful insight
5WaitWait 4 DaysPauses the workflow for 4 more days
6GmailClose EmailSends a "closing the loop" final email
7Google SheetsLog SequenceLogs lead + sequence status to a tracking sheet

Connections

New Lead Trigger → Welcome Email → Wait 3 Days → Value Follow-Up → Wait 4 Days → Close Email → Log Sequence

2. Weekly Client Report

What it does: Every Monday at 9am, it pulls task data from ClickUp, sends the raw data to Claude for a professional summary, and emails the formatted report to the client. No more spending 45 minutes writing weekly updates manually.

Setup time: 25-30 minutes

Node List (5 nodes)

#Node TypeNamePurpose
1Schedule TriggerMonday 9amFires every Monday at 9:00 AM
2HTTP RequestGet ClickUp TasksPulls tasks from ClickUp API (completed last 7 days + in progress)
3HTTP RequestClaude SummarySends task data to Claude API for a professional summary
4GmailSend ReportEmails the formatted report to the client
5Google SheetsLog ReportLogs report date + summary to a tracking sheet

Connections

Monday 9am → Get ClickUp Tasks → Claude Summary → Send Report → Log Report

ClickUp API Setup (Node 2)

URL: https://api.clickup.com/api/v2/list/[LIST_ID]/task
Method: GET
Headers: Authorization: [YOUR_CLICKUP_API_KEY]
Query params:
  statuses[]: complete
  statuses[]: in progress
  date_updated_gt: {{$now.minus(7, 'days').toMillis()}}

Claude Prompt (Node 3)

URL: https://api.anthropic.com/v1/messages
Method: POST
Headers:
  x-api-key: [YOUR_CLAUDE_API_KEY]
  anthropic-version: 2023-06-01
  Content-Type: application/json
Body:
{
  "model": "claude-sonnet-4-20250514",
  "max_tokens": 1024,
  "messages": [{
    "role": "user",
    "content": "You are a project manager writing a weekly client report. Summarize these ClickUp tasks into a professional weekly update email. Group by: Completed This Week, In Progress, and Next Steps. Keep it under 200 words. Be specific about what was done.\n\nTasks:\n{{$json.tasks}}"
  }]
}

3. New Client Onboarding

What it does: When a new client signs (triggered by webhook from your payment tool or manual trigger), it automatically creates a ClickUp project from a template, sends a welcome email with next steps, and posts a notification in your Slack channel. The entire onboarding checklist runs without you lifting a finger.

Setup time: 20-25 minutes

Node List (5 nodes)

#Node TypeNamePurpose
1WebhookNew Client TriggerReceives client info (name, email, project type, start date)
2HTTP RequestCreate ClickUp ProjectCreates a new list in ClickUp with pre-set tasks
3GmailWelcome EmailSends onboarding email with next steps
4SlackTeam NotificationPosts in your #clients Slack channel
5Google SheetsLog ClientAdds client to your master client tracker

Connections

New Client Trigger → Create ClickUp Project → Welcome Email → Team Notification → Log Client

Note: Nodes 3, 4, and 5 can run in parallel after Node 2 if you prefer. In n8n, connect Node 2's output to all three.

ClickUp Project Creation (Node 2)

URL: https://api.clickup.com/api/v2/folder/[FOLDER_ID]/list
Method: POST
Headers: Authorization: [YOUR_CLICKUP_API_KEY]
Body:
{
  "name": "{{$json.client_name}} — {{$json.project_type}}",
  "content": "Client: {{$json.client_name}}\nEmail: {{$json.client_email}}\nStart: {{$json.start_date}}",
  "status": "active"
}

4. Content Repurposer

What it does: You paste a content topic or raw notes into a Google Sheet. The workflow reads new rows, sends them to Claude to generate (1) a short-form video script, (2) an Instagram carousel outline, and (3) a LinkedIn post — then writes all three back to the sheet. One idea becomes 3 pieces of content in under 2 minutes.

Setup time: 25-30 minutes

Node List (6 nodes)

#Node TypeNamePurpose
1Schedule TriggerEvery 30 MinChecks the sheet for new rows every 30 minutes
2Google SheetsRead New TopicsReads rows where "Status" column is empty
3HTTP RequestClaude — Video ScriptGenerates a short-form video script (60-90 sec)
4HTTP RequestClaude — Instagram CarouselGenerates a 7-slide carousel outline
5HTTP RequestClaude — LinkedIn PostGenerates a LinkedIn post (hook + body + CTA)
6Google SheetsWrite ResultsWrites all 3 outputs back to the row + sets status to "Done"

Connections

Every 30 Min → Read New Topics → Claude — Video Script → Claude — Instagram Carousel → Claude — LinkedIn Post → Write Results

Google Sheet Setup

Create a sheet called "Content Pipeline" with columns: Topic, Raw Notes, Video Script, Instagram Carousel, LinkedIn Post, Status, Date Processed.

Claude — Video Script Prompt (Node 3)

Body:
{
  "model": "claude-sonnet-4-20250514",
  "max_tokens": 1024,
  "messages": [{
    "role": "user",
    "content": "Write a 60-90 second short-form video script about this topic. Use a strong hook in the first line. Include exactly 3 key points. End with a clear CTA. Format: HOOK → POINT 1 → POINT 2 → POINT 3 → CTA. Keep it conversational and punchy.\n\nTopic: {{$json.Topic}}\nNotes: {{$json['Raw Notes']}}"
  }]
}

Claude — Instagram Carousel Prompt (Node 4)

Body:
{
  "model": "claude-sonnet-4-20250514",
  "max_tokens": 1024,
  "messages": [{
    "role": "user",
    "content": "Create a 7-slide Instagram carousel outline about this topic. Slide 1: Hook/title (make them stop scrolling). Slides 2-6: One key insight per slide with a bold headline + 1-2 supporting sentences. Slide 7: CTA (follow + save + share). Keep text short — each slide should be readable in 3 seconds.\n\nTopic: {{$json.Topic}}\nNotes: {{$json['Raw Notes']}}"
  }]
}

Claude — LinkedIn Post Prompt (Node 5)

Body:
{
  "model": "claude-sonnet-4-20250514",
  "max_tokens": 1024,
  "messages": [{
    "role": "user",
    "content": "Write a LinkedIn post about this topic. Structure: 1-line hook (pattern interrupt or bold claim) → 1 line of whitespace → 5-7 lines of body (story or teaching) → CTA asking readers to comment or DM. Use short paragraphs. No hashtags. No emojis. Under 200 words.\n\nTopic: {{$json.Topic}}\nNotes: {{$json['Raw Notes']}}"
  }]
}

5. Invoice Reminder

What it does: Every weekday morning, it reads your invoices Google Sheet, filters for overdue invoices (due date is in the past + status is "unpaid"), sends a polite reminder email for each, and logs that the reminder was sent. No more chasing payments manually.

Setup time: 15-20 minutes

Node List (5 nodes)

#Node TypeNamePurpose
1Schedule TriggerWeekdays 9amFires Monday-Friday at 9:00 AM
2Google SheetsRead InvoicesReads all rows from the invoices sheet
3IFFilter OverduePasses through only rows where due_date < today AND status = "unpaid"
4GmailSend ReminderSends a polite payment reminder to each overdue client
5Google SheetsLog ReminderUpdates the row with "Reminder Sent" + today's date

Connections

Weekdays 9am → Read Invoices → Filter Overdue → Send Reminder → Log Reminder

Google Sheet Setup

Create a sheet called "Invoices" with columns: Client Name, Client Email, Invoice Number, Amount, Due Date, Status, Reminder Sent, Reminder Date.

IF Node Configuration (Node 3)

Conditions (AND):
  - {{$json.Status}} equals "unpaid"
  - {{$json['Due Date']}} is before {{$now.format('yyyy-MM-dd')}}

Output: TRUE branch → Send Reminder
        FALSE branch → (no action, end)

Reminder Email (Node 4)

Subject: Friendly reminder — Invoice #{{$json['Invoice Number']}} ({{$json.Amount}})

Hi {{$json['Client Name']}},

Hope you're doing well. Quick reminder that Invoice #{{$json['Invoice Number']}} for {{$json.Amount}} was due on {{$json['Due Date']}}.

If it's already been sent, please disregard this note. If not, here are the payment details:

- Amount: {{$json.Amount}}
- Invoice #: {{$json['Invoice Number']}}
- Payment link: [Your payment link]

Let me know if you have any questions or need me to resend the invoice.

Thanks,
[Your name]

Log Update (Node 5)

Update the matching row: set "Reminder Sent" to "Yes" and "Reminder Date" to today's date. Use the row number from Node 2 to target the correct row.
