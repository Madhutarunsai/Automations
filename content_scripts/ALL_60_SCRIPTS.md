### SCRIPT 29 — How to Reverse Engineer Any Tool
**Week 5 Tue | Lead magnet: AUTOMATION**

I've built automations for tools with zero API documentation. Here's the method.

Open your browser's Dev Tools. Right-click. Inspect. Network tab.

Manually do the action you want to automate. Click the button. Fill the form.

Watch the Network tab. You'll see the API call. The URL. The method — POST means create, PUT means update, GET means read. And the payload.

Copy that payload. Put it into n8n as an HTTP request. Call the same URL with the same method. Same result as clicking manually.

Test it once. Add error handling. Sleep nodes for rate limits. Retry logic.

This isn't a hack. It's how the internet works under the hood. You're just looking at it.
