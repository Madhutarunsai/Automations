## Format

Every script follows the Scarpati 60-second structure:

```

SETUP   (3–10s)  Name the enemy / the lie / the problem
STORY   (10–40s) ONE name, ONE moment, ONE transformation
LESSON  (40–50s) The takeaway in one sentence
CTA     (50–60s) One ask. Urgent. Keyword-based.
```
